# Yantu 阶段性项目进程报告

更新日期：2026-08-31
当前应用版本：v0.2.1
当前数据库版本：Schema v9
开发分支：`main`

## 1. 当前阶段结论

Yantu 已从基础任务清单发展为可安装的 Windows 本地科研时间管理工作台。当前主链路已经覆盖任务与项目、长期任务动态规划、课表、专注计时、专注习惯、Zotero 只读联动、AI 任务拆解、外观设置、本地备份和 Windows 安装准备。

本次审计修复了两个会直接影响使用感受的问题：

1. 规划偏好过去只有在生成规划预览时才会保存。现在提供“仅保存偏好”，专注工作台会显示实际采用的专注/休息时长，并由服务端再次读取当前规划偏好，避免只依赖浏览器状态。
2. 专注习惯过去依赖后台线程采样，部分运行方式下虽然方案已选择，界面数值却不变化。现在页面轮询也会触发一次安全采样；后台线程继续负责面板收起后的记录。新建或编辑方案后，该方案自动成为下一轮选择。

## 2. 阶段进程

### 阶段 A：基础任务与分层架构 — 已完成

- Project、Task、TimeEntry 数据模型与兼容字段同步。
- Task 优先级、状态、Deadline、预计/实际工时和父子任务。
- API → Service → Repository → SQLite 分层。
- 旧 SQLite 数据兼容迁移、幂等初始化和高版本保护。
- 项目及任务 CRUD、筛选、排序、软删除、恢复和永久删除。

### 阶段 B：科研规划与日程 — 已完成

- 长期任务根据剩余工作量和 Deadline 动态计算每日建议投入。
- 规划偏好、任务级规划约束、规则预览和人工确认。
- 课程固定占用、切换缓冲、短休息和长休息。
- 已确认规划快照与当前任务投影比较，过期时提示重新规划。
- 未来 7 天时间轴同时显示课程、计划块、任务开始和 Deadline。

### 阶段 C：课表与课程事件 — 已完成基础能力

- Semester、Course、CourseMeeting、CourseException 和导入批次。
- CSV/XLSX 稳定导入；图片 OCR 采用可选 PaddleOCR 适配器。
- 识别预览、字段修正、重复检测、冲突警告和单事务确认。
- 周次、单双周、指定周、跳过单次课程及课程软删除。

人工验收仍需安装 `requirements-ocr.txt` 后使用真实中文课表图片；自动测试不会下载 OCR 模型。

### 阶段 D：专注工作台 — 已完成并持续优化

- 番茄倒计时与自由正向计时、暂停/恢复、重启恢复和到时确认。
- FocusSession、TimeEntry、Task.actual_minutes 与 PlanBlock 一致性。
- 自动短休息、周期性长休息、提示音、通知和最近 7 天统计。
- 首页任务进行状态、实时投入和预计完成度联动。
- 规划偏好可独立保存；启动时由服务端应用当前模式和时长。
- 提前结束确认及防误触快捷键。

### 阶段 E：专注习惯与隐私保护 — 已完成基础闭环

- 代码、阅读、写作等可配置目标应用方案。
- Windows 前台进程、有效专注、空闲、非目标应用和切换次数聚合。
- 不采集按键内容、窗口标题、网址、截图、鼠标位置或文件路径。
- 页面轮询与后台线程双通道采样，暂停和休息不累计。
- 单轮质量复盘、28 天汇总和连续学习天数。
- 方案保存后自动用于下一轮，启动前仍可选择“不监测应用”。

该能力仅在 Windows 提供系统级采样；其他平台会明确降级，普通计时不受影响。

### 阶段 F：Zotero 科研联动 — 已完成第一阶段

- 本机 Zotero API 与 Zotero Web API 两种只读来源。
- 连接测试、增量同步、删除同步、Server ID 和游标保护。
- 科研项目按文件夹递归导入或题录检索导入。
- 论文收件箱、论文转任务预览/确认和 Zotero 客户端直达链接。
- API Key 使用 Windows Credential Manager，不进入数据库、日志或备份。

当前不写回 Zotero、不解析 PDF 全文、不下载附件，也不后台自动同步。真实本机联动需要 Zotero 正在运行并开放本地 API。

### 阶段 G：AI、安全设置与本地应用 — 已完成基础能力

- DeepSeek API Key 软件内配置、删除和连接测试。
- AI 拆解输出严格限制为 3–8 个子任务，先预览后确认。
- 每次启动随机同源请求令牌保护修改型本地 API。
- AppPaths 分离只读程序资源、用户数据、临时文件和秘密凭据。
- pywebview 桌面壳、单实例、PyInstaller onedir 与 Inno Setup 安装流程。
- JSON 备份兼容旧版本，秘密和活动计时不会导出。

安装包尚未进行商业代码签名；Windows SmartScreen 可能提示未知发布者。

## 4. 已知限制与风险

- 自动测试不访问网络，因此 DeepSeek、Zotero Web API 和真实 Zotero 本机文库需要独立人工冒烟验证。
- PaddleOCR 为大体积可选依赖，真实图片识别效果取决于模型、课表布局和本机环境。
- 专注习惯依据前台进程与系统空闲时间，只能判断“正在使用哪个应用”，不能判断阅读质量或具体工作内容。
- 当前为单用户、本地优先应用，无账号、云同步和跨设备合并。
- 数据库已为安装版放入用户数据目录；正式发布新安装包前仍应执行冻结环境 smoke test、安装/升级/卸载和数据保留验证。

## 5. 下一阶段建议

1. 为任务增加可发现的“规划约束”编辑入口，让任务级每日上限、偏好星期和可用时段不再只存在于 API。
2. 将已确认计划块的时长直接带入专注工作台，并明确显示“来自今日计划”。
3. 增加专注结束后的轻量反思标签，例如“顺利 / 被打断 / 估时不足”，为未来 AI 调整工作量提供结构化依据。
4. 为 Zotero 增加可选定时同步和论文附件存在性检查，仍保持只读、不解析正文的安全边界。
5. 使用真实中文课表、真实 Zotero 文库和有效 DeepSeek Key 建立发布前人工验收清单。
6. 在新版本发布前重建安装包并等待 GitHub Actions 与安装 smoke test 均明确成功。
